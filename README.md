# ODP IT Bank Jakarta 2026
## Day 7 — Integration & DevOps
### CI/CD, Docker & Application Deployment

This repository is the practical companion for **Day 7** of the ODP IT Bank Jakarta 2026 program.

The main hands-on project is **your group's ongoing project from the previous workshop days**. The included `sample-app/` is only an instructor demo and fallback environment.

```text

      ↓

```

## Start Here
1. Read [Participant Requirements](REQUIREMENTS.md).
2. Open your group's existing project repository.
3. Follow the [Workshop Guide](WORKSHOP.md).
4. Use [`templates/`](templates/) as references.
5. Complete the [Group Checklist](GROUP-CHECKLIST.md).
6. Demonstrate your deployed prototype at the end of the session.

## Learning Focus
- CI/CD and DevOps workflow
- Docker and deployment
- Environment configuration
- Deployment verification and troubleshooting

## Activities
- CI/CD and Docker instructor demonstrations
- Apply CI/CD to each group's ongoing project
- Build and deploy the prototype
- Test, troubleshoot, and verify deployment

## End-of-Day Output
Each group should demonstrate:
- a working CI pipeline;
- a deployable project artifact;
- appropriate environment/deployment configuration;
- a deployed and verified prototype; and
- evidence of basic logging/troubleshooting.

## Important Principle
**CI/CD is a software delivery practice. Docker is one possible implementation technology within that practice.**
