# Day 7 Group Checklist

## Repository & Baseline
- [ ] Latest project is in GitHub.
- [ ] All group members can access it.
- [ ] Application runs locally.
- [ ] Build/run commands are documented.

## Continuous Integration
- [ ] CI workflow exists.
- [ ] Workflow runs on push and/or pull request.
- [ ] Automated build/checks run.
- [ ] Failed checks stop progression.
- [ ] At least one successful CI run is visible.

## Deployment Preparation
- [ ] Deployable artifact can be produced.
- [ ] Dockerfile exists where applicable.
- [ ] Environment-specific configuration is separated from source code.
- [ ] Real secrets are not committed.

## Delivery / Deployment
- [ ] Artifact can be published/distributed where applicable.
- [ ] Prototype is deployed or runnable in the agreed target environment.
- [ ] Deployment is reproducible from documented steps/configuration.

## Verification & Troubleshooting
- [ ] Prototype functionality is verified.
- [ ] Logs or equivalent operational evidence can be inspected.
- [ ] Group diagnosed at least one CI/deployment issue.
- [ ] Group can explain the root cause and resolution.

## End-of-Day Demo
- [ ] Prototype ready.
- [ ] Successful pipeline ready to show.
- [ ] Deployment evidence ready.
- [ ] Verification evidence ready.
- [ ] One troubleshooting example ready to explain.
