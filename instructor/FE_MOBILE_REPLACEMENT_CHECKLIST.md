# Five-Minute Replacement Checklist

Frontend update received:
- [ ] Copy official project into `apps/frontend`.
- [ ] Identify build command.
- [ ] Identify runtime port.
- [ ] Set API base URL.
- [ ] Run `bash scripts/frontend-ci.sh`.
- [ ] Test health/account/transaction/mutations.

Mobile update received:
- [ ] Copy official project into `apps/mobile`.
- [ ] Confirm `gradlew` or Gradle project exists.
- [ ] Confirm Java/Android SDK requirements.
- [ ] Set API base URL for emulator/device.
- [ ] Run `bash scripts/mobile-ci.sh` or GitHub workflow.
- [ ] Confirm APK/AAB appears.

If any replacement is unstable, use the fallback for the facilitator demonstration and let participant groups use their own project where available.
